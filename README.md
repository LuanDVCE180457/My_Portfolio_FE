# My Portfolio FE

Portfolio React + TypeScript chạy độc lập trên Vite. Toàn bộ nội dung CV nằm trong frontend, không cần backend, database hay biến môi trường API.

## Chạy dự án

```bash
npm install
npm run dev
```

## Cập nhật nội dung CV

Chỉnh dữ liệu tại `src/data/cvData.ts`. Các kiểu dữ liệu tương ứng nằm trong `src/types`.

## Kiểm tra bản production

```bash
npm run build
npm run preview
```
